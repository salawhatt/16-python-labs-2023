# Лабораторные по цифровым компетенциям
- 'windows-cli' — операции с файлами и реестром Windows. Справка — 'python main.py --help'.
- 'schedule-parser' — разбор расписания СПбПУ. Установите зависимости через 'python -m pip install -r requirements.txt'. Работа зависит от HTML сайта.
- 'image-classification' — классификатор изображений на TensorFlow. 'main.py' принимает три пути — train, valid и test. В train и valid нужны подпапки dogs и people. В test положите отдельные JPEG, PNG или BMP. Установите зависимости командой 'python -m pip install -r requirements.txt' и запустите 'python main.py train valid test'.
